# plans — implementation detail

**Parent:** [docs](../README.md)

How an approved proposal gets built. Every plan names the proposal it serves.

## How to read this directory

**Newest first.** Every file is dated and nothing here is rewritten, so an old record still says what it said. Check `status` before relying on one — retired records stay in place on purpose, and the trail of what was rejected is usually the most useful thing here.
